# Handoff to OpenCode

## What exists

- Product direction and MVP scope.
- OpenCode instructions and commands.
- Existing viewer in `legacy/index.html`.
- Current historical GeoJSON in `data/historical-basemaps/world_100.geojson`.

## What OpenCode should do first

Use Plan agent and paste `OPENCODE_START_PROMPT.md`.

## Human approval gates

The CEO should approve:

1. Milestone 0 plan.
2. Dependency choices.
3. Token/base-map strategy.
4. Any destructive geometry transformation.
5. Public data attribution/license text.
6. Deployment to `historyatlas.net`.

## Do not let the agent drift into

- full platform architecture,
- dataset registry research,
- AI chat,
- creator video export,
- authentication,
- subscriptions,
- universal geometry repair.

These are post-launch topics.
